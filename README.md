# 파이널 컷 · 7주 데일리 체크 캘린더

9.15 – 10.31 · 목표 −8kg. 매일 셀을 눌러 **지킴 / 애매 / 못 지킴**을 기록하고, 체중 게이지·연속 기록·진행률을 확인하는 웹앱입니다.

브라우저에 설치하면 **바탕화면 아이콘**으로 열 수 있고(자체 창), **오프라인**에서도 동작합니다. 체크 기록은 사용하는 브라우저에 저장됩니다.

## 바탕화면에 추가하기 (설치)

먼저 배포된 주소를 브라우저(크롬/엣지)에서 엽니다.

**Windows · Mac (크롬 / 엣지)**
1. 주소창 오른쪽의 **설치 아이콘**(⤓ 또는 모니터 모양)을 클릭
   - 안 보이면: 오른쪽 위 **⋮ 메뉴 → 앱 → "파이널 컷 설치"** (엣지는 **⋯ → 앱 → 이 사이트를 앱으로 설치**)
2. **설치**를 누르면 바탕화면/시작 메뉴에 아이콘이 생기고, 독립 창으로 열립니다.

**iPhone / iPad (사파리)**
- **공유 → 홈 화면에 추가**

**Android (크롬)**
- **⋮ 메뉴 → 홈 화면에 추가 / 앱 설치**

> 설치 옵션이 안 뜨면 HTTPS 주소(예: GitHub Pages)에서 열었는지 확인하세요. 로컬 파일(`file://`)에서는 설치가 안 됩니다.

## 사용법

- **날짜 셀 탭**: 빈칸 → ✓ 지킴 → △ 애매 → ✕ 못 지킴 → 다시 빈칸 (순환)
- **오늘 체중**: −/+ 로 0.1kg 단위 조절 (게이지 자동 갱신)
- **🖨️ / ⋯ → 인쇄**: A4 세로로 인쇄/PDF 저장
- **⋯ → 전체 초기화**: 모든 체크·체중 리셋

## 구조

정적 사이트라 빌드 없이 그대로 서빙됩니다.

```
index.html              앱 진입점 (매니페스트·서비스워커 등록)
app.js                  화면 로직 (src/app.jsx 를 컴파일한 결과)
src/app.jsx             원본 소스 (React)
vendor/react*.min.js    React 로컬 번들 (오프라인 동작용, CDN 불필요)
sw.js                   서비스 워커 (오프라인 캐시)
manifest.webmanifest    PWA 매니페스트
icons/                  앱 아이콘
```

## 로컬에서 실행

```bash
npm run serve            # http://localhost:8899 에서 열기
```

## 소스 수정 후 다시 빌드

`src/app.jsx` 를 고친 뒤:

```bash
npm install              # 최초 1회 (Babel 설치)
npm run build            # src/app.jsx → app.js 재컴파일
```

React 로컬 번들을 갱신하려면 `npm run vendor` 를 실행합니다.
앱 내용을 바꿔 배포할 때는 `sw.js` 의 `CACHE` 버전(`final-cut-v1` → `v2` …)을 올려야 사용자에게 갱신본이 전달됩니다.

## 배포 (GitHub Pages)

빌드가 필요 없는 정적 사이트라, 브랜치에서 바로 서빙합니다. **최초 1회만** 설정하면 됩니다.

1. 저장소 **Settings → Pages** 이동
2. **Build and deployment → Source** 를 **Deploy from a branch** 로 선택
3. **Branch** 를 `main`, 폴더는 `/ (root)` 로 두고 **Save**

몇 분 뒤 `https://amelialeecan-art.github.io/7-/` 에서 열립니다.
이후 `main` 에 푸시하면 자동으로 갱신됩니다.
앱 내용을 바꿀 때는 `sw.js` 의 `CACHE` 버전(`final-cut-v1` → `v2` …)을 올려야 기존 사용자에게 갱신본이 전달됩니다.
